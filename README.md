## ✦ Core Design Philosophy & Architecture

Vision Pro 2 is engineered to break away from generic, cluttered e-commerce templates. It provides an editorial luxury experience inspired by Apple, Leica, and high-end architectural monographs:

- **100% Fluid Responsive System**: Fully responsive from 320px ultra-compact phones to 4K ultra-wide monitors with dynamic clamp scaling, touch-optimized targets, and zero horizontal scroll leaks.
- **60fps Native Vanilla Motion Engine**: Hardware-accelerated IntersectionObserver scroll reveals, parallax media containers, and fluid element entrances without jQuery or bloated animation libraries.
- **Full Shopify Theme Customizer Freedom**: Every single section, block, typography scale, color token, button label, and wordmark can be customized, rearranged, or removed directly in the visual Theme Editor.
- **High-Velocity Conversion Rate Optimization (CRO)**:
  - Slide-out AJAX cart drawer with tiered free-shipping progress tracker and 1-click cross-sells.
  - Real-time dynamic delivery countdown timer.
  - Live scarcity inventory indicator (`⚡ Only 4 units remaining in current batch`).
  - Sticky Add to Cart bar sliding in smoothly on scroll with live variant price.
  - 1-click accelerated checkout compatibility (Shop Pay, Apple Pay, Google Pay, PayPal).
- **Internationalization (i18n)**: Multi-language architecture with complete English (`en.default.json`) and Turkish (`tr.json`) translation coverage.

## ✦ Installation & Setup

### Method 1: Shopify CLI (Recommended for Developers)

```bash
# 1. Clone the repository
git clone https://github.com/berkaysahin-dev/Vision-Pro-2-Shopify-Theme.git
cd Vision-Pro-2-Shopify-Theme

# 2. Push directly to your Shopify store
shopify theme push --store your-store.myshopify.com

# 3. Start local development server with hot-reload
shopify theme dev --store your-store.myshopify.com
```

### Method 2: Manual ZIP Upload

1. Download the latest release: [`Vision-Pro-2-Theme.zip`](https://github.com/berkaysahin-dev/Vision-Pro-2-Shopify-Theme/releases/latest)
2. In Shopify Admin, go to **Online Store → Themes**.
3. Under **Theme Library**, click **Add theme → Upload zip file**.
4. Select `Vision-Pro-2-Theme.zip` and click **Publish**.
